# 📊 Data Models

> **Status:** Placeholder — Framework-dependent implementation.

Core data models for the Story App:

- **Scene** — A single narrative moment with choices and branches
- **Character** — A story character with personality, relationships, and state
- **Item** — An artifact or object with properties and effects
- **WorldNode** — A location or region in the Shattered Realm
- **StoryState** — Player state, flags, inventory, and progress
- **Choice** — A player decision with consequences and next scenes

See [PROJECT_TYPE.md](../PROJECT_TYPE.md) for framework-specific model patterns.
